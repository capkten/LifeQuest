# LifeQuest 修仙世界与生活闯关系统设计

> 状态：设计草案，待产品确认后进入实现计划
> 日期：2026-08-17
> 适用范围：单人修仙 RPG、现实待办驱动、九星宗门、地图闯关、功法构筑、仙界官署

## 1. 设计目标

LifeQuest 保留现有的任务、习惯、目标、项目、商城、成就和统计能力，在其上增加一层单人修仙 RPG。用户只需要完成现实中的待办，系统把完成结果转换为修为、灵石、功德、地图进度和角色成长。

核心原则：

1. 现实任务是主要行动来源，不能通过重复点击或虚构任务无限刷资源。
2. 游戏层增加目标感、反馈和长期构筑，但不能要求用户重复录入同一件事。
3. 单人世界也必须有完整的宗门、NPC、地图和事件，NPC 负责提供世界感和成长选择。
4. 失败和延期可以产生游戏反馈，但不能用严重惩罚伤害用户的现实生活习惯。
5. 奖励、幂等和资源变更由后端计算，前端不能直接决定数值。

## 2. 当前项目的复用边界

现有对象与修仙对象的映射如下：

| 当前对象 | 修仙表现 | 说明 |
| --- | --- | --- |
| Habit | 每日修炼、巡山、据点守护 | 连续完成产生心境和资质收益 |
| Task | 单次历练、除妖、采集、学习 | 一条任务对应一次结算 |
| Goal | 悬赏、精英挑战 | 需要更高难度或多个条件 |
| Subtask | 关卡目标、战斗阶段 | 归属于 Task，不单独创建游戏任务 |
| Project | 秘境、副本 | 项目阶段组成区域，里程碑组成 Boss |
| ProjectPhase | 秘境区域 | 完成后开放下一段地图 |
| ProjectMilestone | 精英怪或 Boss | 产生阶段性奖励 |
| Shop | 灵石商城 | 出售格子、材料、外观和有限消耗品 |
| Achievement | 成就、天道记录 | 发放一次性奖励和称号 |
| Stats | 修炼日志、境界统计 | 展示当前和历史成长 |

金融和笔记模块默认不直接发放大量修为。记账可以通过每日一次的“清点功德”获得少量功德，笔记可以通过用户主动标记为修炼记录获得心境加成，避免为了刷奖励制造虚假数据。

## 3. 核心循环

```text
创建现实任务
  -> 系统计算任务星级和基础奖励
  -> 用户完成任务
  -> 后端结算修为、灵石、功德和资质点
  -> 推进地图节点、宗门任务或项目副本
  -> 达到阶段阈值
  -> 完成突破试炼
  -> 解锁新境界、地图、宗门和功法
```

每日循环：

1. 查看今日历练和当前地图。
2. 选择 3 至 5 个现实任务作为今日主要行动。
3. 完成任务并获得即时战斗反馈。
4. 习惯任务累计连续天数和心境。
5. 项目阶段推动副本进度。
6. 每日结束显示修炼日志、资源变化和下一步目标。

长期循环：

```text
散修 -> 炼气九层 -> 筑基试炼 -> 选择一星宗门
    -> 宗门贡献与功法构筑 -> 金丹 -> 更高星级宗门
    -> 秘境、师徒、宗门主线 -> 高阶境界与天道试炼
    -> 渡劫准备 -> 渡劫 -> 飞升 -> 仙宗与仙官并行 -> 仙王、准圣、圣人
```

## 4. 境界与修为

### 4.1 境界

```text
炼气：一层至九层
筑基：初期、中期、后期、圆满
金丹：初期、中期、后期、圆满
元婴：初期、中期、后期、圆满
化神：初期、中期、后期、圆满
炼虚：初期、中期、后期、圆满
合体：初期、中期、后期、圆满
大乘：初期、中期、后期、圆满
渡劫：初期、中期、后期、圆满
```

筑基是世界结构切换点。炼气期只开放散修地图，筑基后才正式接触宗门。宗门星级不等同于境界等级，但默认要求逐级提高。

### 4.2 阶段阈值

阈值表示进入当前阶段后需要获得的修为。阶段突破后当前修为清零，道行累计不清零。

| 境界 | 阶段阈值 |
| --- | --- |
| 炼气 | 100 / 110 / 120 / 130 / 145 / 160 / 180 / 205 / 235 |
| 筑基 | 500 / 600 / 750 / 950 |
| 金丹 | 1000 / 1300 / 1700 / 2000 |
| 元婴 | 1500 / 2200 / 2800 / 3500 |
| 化神 | 2500 / 3500 / 4500 / 5500 |
| 炼虚 | 4500 / 6000 / 8000 / 9500 |
| 合体 | 7500 / 10000 / 13000 / 17500 |
| 大乘 | 12000 / 16000 / 22000 / 30000 |
| 渡劫 | 20000 / 26000 / 35000 / 49000 |

平衡目标：普通用户每天完成 3 至 5 个任务和 1 个习惯，获得约 55 至 95 点修为；炼气到筑基的基础周期约 17 至 26 天，完成 4 个普通任务的用户在资质点成长后约 17 至 20 天，筑基到金丹约 4 至 6 周。按稳定的 4 个普通任务日常完成，凡界九境预计约 3 年；渡劫和飞升后的仙界境界另行进入长期养成，不要求每天大量操作。

### 4.3 突破试炼

达到修为阈值后，系统生成固定的突破前置条件。用户完成条件后，炼气至渡劫阶段进入渡劫准备界面；完成渡劫判定后才进入下一个大境界。小境界内部不进行概率突破。

| 突破 | 条件 |
| --- | --- |
| 炼气九层 -> 筑基 | 一个重要目标、一个习惯连续 7 天、一个三星历练、心境 >= 60 |
| 筑基圆满 -> 金丹 | 一个项目阶段、一个习惯连续 14 天、一个五星历练、宗门贡献 >= 300 |
| 金丹圆满 -> 元婴 | 完成一条宗门主线、一个长期目标阶段、心境 >= 70 |
| 元婴及以后 | 高星秘境、宗门主线和境界试炼共同组成，完成后进入对应渡劫准备 |

前置试炼失败时保留已经完成的条件，只需补齐未完成条件；渡劫失败则按第 4.4 节处理。

### 4.4 渡劫概率与失败

渡劫只发生在跨越大境界时。基础成功率随目标境界提高而降低，最终概率直接展示给用户，不存在隐藏修正，也不设置连续失败保底。

| 渡劫节点 | 基础成功率 | 失败修为损失 |
| --- | ---: | ---: |
| 炼气九层 -> 筑基 | 90% | 当前小境界阈值的 10% |
| 筑基圆满 -> 金丹 | 80% | 当前小境界阈值的 10% |
| 金丹圆满 -> 元婴 | 70% | 当前小境界阈值的 12% |
| 元婴圆满 -> 化神 | 60% | 当前小境界阈值的 15% |
| 化神圆满 -> 炼虚 | 50% | 当前小境界阈值的 18% |
| 炼虚圆满 -> 合体 | 40% | 当前小境界阈值的 20% |
| 合体圆满 -> 大乘 | 30% | 当前小境界阈值的 22% |
| 大乘圆满 -> 渡劫 | 25% | 当前小境界阈值的 25% |
| 渡劫圆满 -> 飞升 | 20% | 当前小境界阈值的 25% |

渡劫准备度为 0 至 100 分，由以下项目组成：

| 准备项 | 权重 |
| --- | ---: |
| 心境状态 | 25% |
| 最近 7 天习惯完成情况 | 20% |
| 最近 7 天任务完成质量 | 20% |
| 渡劫试炼完成质量 | 20% |
| 功法、宗门与当前流派契合度 | 15% |

```text
准备度加成 = round((渡劫准备度 - 50) / 5)
渡劫丹加成 = 渡劫丹数量 × 5%
最终成功率 = clamp(基础成功率 + 准备度加成 + 渡劫丹加成, 20%, 95%)
```

渡劫界面必须展示基础成功率、每项准备度得分、准备度加成、渡劫丹加成和最终成功率。渡劫判定由后端执行并写入 `TribulationAttempt`，前端不能传入最终概率。

渡劫失败后：

1. 不降低大境界或小境界名称。
2. 只扣除当前小境界中的部分修为，修为最低为 0。
3. 不删除功法、装备、格子、宗门记录、NPC 关系或仙官职位。
4. 当天不能再次渡劫，次日可以重新准备和尝试。
5. 已完成的突破前置条件保留，但渡劫准备度按当前状态重新计算。

### 4.5 飞升后境界

渡劫圆满成功后进入仙界，初始境界为真仙，不重置角色成长。仙界境界如下：

```text
真仙 -> 玄仙 -> 金仙 -> 太乙 -> 大罗 -> 仙王 -> 准圣 -> 圣人
```

仙界阶段阈值如下，数值只用于仙元进度和失败损失计算：

| 境界 | 阶段阈值 |
| --- | --- |
| 真仙 | 6000 / 8000 / 10500 / 13500 |
| 玄仙 | 9000 / 12000 / 16000 / 20000 |
| 金仙 | 14000 / 18000 / 24000 / 30000 |
| 太乙 | 22000 / 28000 / 36000 / 45000 |
| 大罗 | 35000 / 45000 / 58000 / 72000 |
| 仙王 | 55000 / 70000 / 90000 / 115000 |
| 准圣 | 85000 / 110000 / 145000 / 190000 |
| 圣人 | 130000 / 170000 / 220000 / 300000 |

每个仙界大境界仍包含初期、中期、后期、圆满；跨越仙界大境界同样需要渡仙劫。飞升后已达到渡劫概率下限，因此以下仙劫基础成功率均为 20%，准备度和仙劫丹可以提高最终概率，但不能低于 20% 或高于 95%。

| 仙劫节点 | 基础成功率 | 失败修为损失 |
| --- | ---: | ---: |
| 真仙圆满 -> 玄仙 | 20% | 当前小境界阈值的 25% |
| 玄仙圆满 -> 金仙 | 20% | 当前小境界阈值的 25% |
| 金仙圆满 -> 太乙 | 20% | 当前小境界阈值的 28% |
| 太乙圆满 -> 大罗 | 20% | 当前小境界阈值的 30% |
| 大罗圆满 -> 仙王 | 20% | 当前小境界阈值的 32% |
| 仙王圆满 -> 准圣 | 20% | 当前小境界阈值的 35% |
| 准圣圆满 -> 圣人 | 20% | 当前小境界阈值的 40% |

真仙至太乙优先开放仙界地图和仙官系统，大罗至圣人开放仙域治理、圣道试炼和终局道果。圣人是当前规划的终局境界，不再继续增加更高境界。

## 5. 资源体系

| 资源 | 类型 | 用途 | 来源 |
| --- | --- | --- | --- |
| 修为 | 当前进度 | 境界阶段推进 | 任务、习惯、目标、项目 |
| 道行 | 永久累计 | 成就、称号、长期统计 | 所有修为结算 |
| 灵石 | 通用货币 | 格子、商城、材料和制作 | 任务、目标、项目、成就 |
| 功德 | 长期资源 | NPC 事件、特殊商店和善缘路线 | 习惯、记账、帮助 NPC |
| 宗门贡献 | 宗门内资源 | 职位、功法、宗门商店 | 宗门任务 |
| 心境 | 0-100 状态 | 突破、功法兼容、特殊事件 | 连续习惯、笔记反思、延期调节 |
| 资质点 | 永久成长 | 转换为修炼效率 | 完成任务，日上限控制 |
| 仙元 | 仙界当前进度 | 真仙至圣人阶段推进 | 飞升后任务、仙职和仙界项目 |
| 仙石 | 仙界通用货币 | 仙界格子、仙官资源和高阶商城 | 仙界任务、仙职、仙界秘境 |
| 仙功 | 仙官成长经验 | 官职晋升和官署权限 | 仙官任务和官署主线 |
| 官职表现 | 0-100 状态 | 仙官任务等级、调任和监察 | 仙职履历和日常履职 |

默认不设置体力消耗。用户完成现实任务已经是成本，额外体力系统会把产品变成强制打卡游戏。

## 6. 任务数值

### 6.1 基础值

| 内容类型 | 基础修为 | 灵石比例 |
| --- | ---: | ---: |
| 习惯 | 10 | 修为的 0.35 |
| 普通任务 | 15 | 修为的 0.40 |
| 子任务 | 8 | 修为的 0.30 |
| 目标 | 45 | 修为的 0.45 |
| 项目阶段 | 75 | 修为的 0.50 |
| 项目里程碑 | 120 | 修为的 0.55 |
| 境界试炼目标 | 180 | 修为的 0.60 |

### 6.2 公式

```text
修为奖励 = floor(基础值 × 难度系数 × 重要性系数 × 修炼效率 × 完成质量)
灵石奖励 = max(1, floor(修为奖励 × 灵石比例))
道行增加 = 修为奖励
```

难度系数：简单 0.8、普通 1.0、困难 1.35、极难 1.8。

重要性系数：低 0.8、普通 1.0、重要 1.3、关键 1.6。

完成质量：按时 1.0、提前完成 1.05、延期完成 0.75。没有截止日期的任务按时处理。

用户只选择任务难度和重要性，奖励由服务端根据内容类型计算。现有 `coins_reward` 和 `exp_reward` 在迁移期间保留读取能力，但新创建的任务不允许前端直接指定奖励。

### 6.3 星级

星级用于地图和任务表现，不直接替代修为公式：

| 星级 | 典型内容 |
| --- | --- |
| 1 星 | 整理桌面、阅读十分钟、简单日常 |
| 2 星 | 普通运动、学习、工作事项 |
| 3 星 | 有明确产出的普通任务 |
| 4 星 | 重要工作、复杂学习任务 |
| 5 星 | 项目阶段和高价值目标 |
| 6 星 | 多步骤目标或重要里程碑 |
| 7 星 | 重大项目节点 |
| 8 星 | 长期目标关键节点 |
| 9 星 | 境界试炼、人生级长期目标 |

星级根据类型、难度、重要性和是否为项目节点由后端计算。用户不能通过把任务标记成“关键”无限提高奖励，服务端设置类型上限。

### 6.4 防刷和幂等

1. 每个任务只能有一条奖励流水。
2. 完成接口使用事务和唯一幂等键。
3. 同一任务完成、取消、重开不会重复发放奖励。
4. 每日最多 8 个任务增加资质点，奖励本身仍按任务状态结算。
5. 删除后重建任务不会继承原任务的连续奖励。
6. 项目阶段、里程碑和目标只能按状态机向前推进。
7. 并发完成必须由数据库锁或唯一约束保证只生成一条 reward ledger。

## 7. 修炼速度和资质

境界基础速度：

```text
炼气 1.00    筑基 1.15    金丹 1.35
元婴 1.60    化神 1.90    炼虚 2.25
合体 2.65    大乘 3.10    渡劫 3.60
```

功法速度加成单部功法通常为 +0.05 至 +0.35，所有功法的速度加成总上限为 +0.80。

每完成一星任务增加 1 点资质点；二至三星任务增加 2 点，四至五星任务增加 3 点，六星以上任务增加 4 点。每天前 8 个奖励任务才增加资质点。

```text
资质效率 = min(0.60, 0.04 × sqrt(资质点))
修炼效率 = 境界基础速度 + 功法速度加成 + 资质效率
```

该公式保留“完成一星任务增加一点速度成长”的体验，但避免速度直接等于资质点导致指数爆炸。

## 8. 功法和格子

### 8.1 功法类型

- 主修功法：只能装备一部，决定主要流派。
- 辅修功法：修炼效率、灵石、任务类型或资源加成。
- 身法秘术：影响探索和特殊任务。
- 心法：影响习惯、心境和突破。
- 炼体法：提高延期恢复、连续任务和高难度任务容错。

### 8.2 格子上限和价格

| 境界 | 格子上限 |
| --- | ---: |
| 炼气 | 2 |
| 筑基 | 4 |
| 金丹 | 6 |
| 元婴 | 8 |
| 化神 | 10 |
| 炼虚 | 11 |
| 合体 | 12 |
| 大乘 | 13 |
| 渡劫 | 14 |

格子购买价格：初始格子免费，第 2 格 100 灵石，第 3 格 300，第 4 格 800，第 5 格 2000，第 6 格 5000，第 7 格 12000，之后按 2.4 倍递增。高阶格子同时需要对应境界。

高级功法可以占用 2 格。相同标签的效果采用递减收益；冲突功法无法同时运行。功法学习永久保留，退出宗门后保留通用效果，宗门联动效果失效。

### 8.3 渡劫丹与仙劫丹

商城提供渡劫丹。每颗渡劫丹使本次渡劫成功率增加 5 个百分点，单次渡劫最多使用 15 颗；最终成功率仍受 20% 下限和 95% 上限约束。渡劫丹可以使用灵石购买，也可以从高阶秘境、宗门任务和 NPC 事件获得。

```text
渡劫丹价格 = floor(500 × 1.6 ^ 目标境界序号)
```

飞升后商城提供仙劫丹，效果与渡劫丹相同，但使用仙石购买。渡劫丹和仙劫丹不能在同一次渡劫中混用；两者都只影响当前一次判定，不改变基础概率和准备度。

## 11. 宗门规则

入宗流程：

1. 达到对应境界。
2. 与宗门使者完成初次接触。
3. 完成宗门试炼。
4. 选择加入一个宗门。
5. 获得基础功法、宗门任务和贡献账户。

宗门职位：外门弟子、内门弟子、核心弟子、真传弟子、长老候补。职位由贡献、境界和宗门主线共同决定。

退出宗门：

- 已学习功法保留。
- 宗门贡献冻结，不转换成灵石。
- 宗门联动效果暂时失效。
- 退出后有 7 天冷却，期间不能加入同星级或更高星级宗门。
- 不扣除修为，不降低境界。

换宗门的成本是路线重建，而不是清空角色成长。

## 14. 闯关与 Boss

- 普通任务：一次历练，完成即结算。
- 连续习惯：每日修炼或据点守护。
- 目标：精英任务，需要更高星级。
- 项目：完整秘境。
- 项目阶段：秘境区域。
- 里程碑：精英怪或 Boss。
- 长期目标：区域最终 Boss。
- 境界试炼：主线 Boss。

项目示例：

```text
项目：完成一个大型工作项目
  阶段一：收集情报
  阶段二：建立基础
  阶段三：解决核心问题
  阶段四：最终交付
```

战斗第一版采用自动结算：现实任务完成等于角色行动，装备和功法决定反馈表现，任务星级决定挑战等级。后续可以加入 Boss 前的功法配置和属性克制，但不在第一版加入手动回合战斗。

延期处理：

- 延期任务仍然可以完成，但完成质量为 0.75。
- 习惯中断只降低连续奖励，不删除历史道行。
- 项目阶段延期会增加“心魔”状态，完成一次反思任务即可清除。
- 不使用角色死亡、掉境界或清空功法等高惩罚机制。

### 14.1 仙官职责循环

仙官是飞升后的第二条成长线，与仙宗并行。玩家可以保留仙宗身份，同时申请一个主官署；任职不会改变境界，也不会清除下界功法。

第一阶段开放六个官署：

| 官署 | 现实任务映射 | 主要职责 |
| --- | --- | --- |
| 功德司 | 助人、习惯和善缘 | NPC 帮助、功德事件和善缘路线 |
| 天律司 | 纪律、执行和按时完成 | 守约、延期复盘和连续任务 |
| 司命府 | 目标、项目和人生规划 | 长期目标、项目阶段和仙案 |
| 巡界司 | 运动、出行和探索 | 仙域巡查、秘境和远行任务 |
| 天工司 | 整理、制作和财务 | 仙府建设、资源和装备制作 |
| 典藏司 | 学习、笔记和复盘 | 功法研究、知识任务和心境 |

官职阶梯为候补仙籍、九品至一品仙官、仙卿、仙君、天君和圣位。真仙从仙籍候补开始，玄仙可申请八品或七品，金仙可申请六品或五品，太乙可申请四品，大罗可申请三品，仙王可申请二品或一品，准圣可申请天君，圣人进入圣位。官职晋升同时需要境界、仙功、官职表现和官署主线条件。

仙官任务直接复用现实待办，不要求重复录入：

- 仙职日课：每日习惯和普通任务。
- 巡界令：运动、出行和地图任务。
- 仙案：目标或项目阶段。
- 天律公文：按时完成、整理和复盘。
- 功德诏令：帮助 NPC 或完成善缘事件。
- 官署主线：部门独有的长期任务。

仙官任务奖励仙功、仙石、功德和官署权限。任务失败只降低当期官职表现，不扣除修为、不掉境界、不删除功法；连续表现较差时会暂停高阶任务或触发监察事件。官署普通仙吏按需生成后永久保留，每日更新修为和行程，每周检查晋升、调任和竞争关系，每月检查离任、闭关和飞升。

## 18. 验收标准

功能验收：

1. 用户能从炼气散修开始完成任务并获得修为。
2. 任务重复完成不能重复发奖。
3. 修为达到阈值后能生成并完成突破试炼。
4. 筑基后能查看多个一星宗门并选择加入。
5. 功法学习、格子购买、装备和退出宗门规则正确。
6. 项目可以映射为秘境，阶段可以映射为关卡，里程碑可以映射为 Boss。
7. NPC 对话和好感度按状态机推进。
8. NPC 普通弟子按需生成后永久保留，已生成 NPC 的修为可按自然日补算。
9. 渡劫前端可以展示完整概率组成，后端按幂等记录成功率、骰值和失败损失。
10. 飞升后保留功法、装备、道行、NPC 关系和下界宗门记录。
11. 用户可以加入一个仙官署并完成仙职任务，仙官表现不会直接扣除修为或降低境界。
12. 所有资源变更都有可追溯流水。

数值验收：

1. 普通用户每日 3 至 5 个任务可以稳定推进。
2. 首次筑基基础周期预计 17 至 26 天；完成 4 个普通任务的用户在资质点成长后约 17 至 20 天。
3. 按稳定的 4 个普通任务日常完成，炼气至渡劫的累计周期目标约为 3 年，不超过 4 年。
4. 低难度任务不能通过数量无限压过高难度任务。
5. 功法速度加成和资质点存在软上限。
6. 灵石可以购买格子，但不能在单日内无限购买高阶成长。
7. 延期任务有反馈但不会破坏角色长期进度。
8. 渡劫基础概率随境界降低，最终概率最低 20%、最高 95%；渡劫准备度和渡劫丹加成可被用户解释和验证。
9. 渡劫失败只损失当前小境界修为，不降低境界，不清除功法和装备。
10. 圣人是当前终局境界，飞升后仙界成长不会重置凡界角色。

测试验收：

- 奖励结算、并发幂等、突破条件、宗门加入退出、格子购买、功法冲突必须有后端测试。
- 渡劫准备度计算、概率上下限、渡劫丹、失败修为损失、重复尝试和飞升迁移必须有后端测试。
- 官职申请、仙官任务、表现结算、晋升、调任和监察状态必须有后端测试。
- 前端至少覆盖地图、宗门选择、功法配置、突破试炼、渡劫预览和仙官申请六条核心流程。
- 所有 90 个宗门、9 个凡界大域、3 个仙界大域、18 个凡界世界 NPC、270 个固定核心 NPC、六大官署和普通弟子/仙吏人口规则必须通过种子数据完整性检查。

## 20. NPC 交互契约

### 20.1 宗门 NPC 角色

| 角色 | 解锁 | 固定功能 | 默认奖励 |
| --- | --- | --- | --- |
| 宗主/掌门/府主/阁主 | 初次拜访宗门 | 开启宗门主线、加入和职位晋升 | 一次性 30 功德、宗门基础功法 |

### 20.4 普通弟子人口

每个宗门配置一个普通弟子人口规则。普通弟子不是一次性随机文本，而是按需生成后永久保留的 `NpcInstance`；用户第一次在地图、任务或对话中遇到某个弟子时才创建档案，之后该弟子持续拥有自己的修为、行程、关系和事件记录。

| 人口项 | 规则 |
| --- | --- |
| 每宗门虚拟人口 | 60 至 120 名普通弟子，由宗门星级和宗门规模系数决定 |
| 每宗门当前活跃人口 | 12 至 20 名，作为地图和任务池中的高频可见 NPC |
| 生成方式 | 按需生成；首次遇到时确定姓名、天赋、性格、职位和初始境界 |
| 永久性 | 已生成档案永久保留，不因离线、刷新或换地图删除 |
| 可见性 | 未遇到的弟子只存在于人口统计，不提前占用对话和事件资源 |
| 固定核心 NPC | 每宗门 3 名，和普通弟子一样每日更新修为；剧情锁定的首领可显式设置 `cultivation_locked` |

普通弟子的初始档案使用稳定种子生成，种子由 `sect_id + population_index` 组成。同一个宗门和人口序号必须得到同一个人，避免刷新页面后姓名、性格或境界变化。普通弟子可以晋升为内门弟子、成为任务竞争者、闭关、受伤或离宗；离宗后档案仍保留，并在世界 NPC 列表中显示其去向。

### 20.5 NPC 每日修为结算

NPC 修为以自然日为粒度更新。系统不要求每个 NPC 实时运行后台计时器，而是在每日世界结算或用户打开相关世界页面时，按照 `last_simulated_date` 补算该 NPC 尚未结算的日期。补算最多 30 天；超过 30 天的部分按 30 天封顶，并记录一次“长期闭关/失联”事件，避免长期离线造成无限追赶。

每日基础修为公式：

```text
NPC 每日修为
= floor(
    当前阶段阈值 / 目标天数
    × 天赋系数
    × 勤勉系数
    × 当前状态系数
    × 宗门支持系数
  )
+ 机缘奖励
```

系数由档案和当日状态决定：

| 维度 | 取值或规则 |
| --- | --- |
| 天赋系数 | 0.80 至 1.20，生成后固定 |
| 勤勉系数 | 0.80 至 1.20，受性格、目标和近期事件影响 |
| 机缘系数 | 0.80 至 1.20，生成后固定，用于计算外出事件的机缘奖励 |
| 宗门支持系数 | 普通宗门 1.00；高资源宗门 1.05；资源紧张宗门 0.95 |
| 外门弟子目标天数 | 45 天完成当前阶段 |
| 内门弟子目标天数 | 35 天完成当前阶段 |
| 核心弟子目标天数 | 25 天完成当前阶段 |
| 长老或特殊 NPC 目标天数 | 20 天完成当前阶段 |
| 隐藏天才目标天数 | 15 天完成当前阶段 |

当前状态系数固定为：正常修炼 `1.0`、闭关 `1.5`、外出任务 `0.8`、受伤或低迷 `0.4`、突破瓶颈 `0.2`。外出任务可以根据当日事件增加 0 至 20 点机缘奖励；机缘奖励来源必须写入事件流水，不能通过刷新重复领取。

每日结算顺序固定为：

1. 根据自然日差计算待补算天数，并应用 30 天上限。
2. 为每个待结算日读取稳定的 `NpcSchedule`，确定修炼、闭关、外出或恢复状态。
3. 依据公式增加当前阶段修为，达到阈值后标记为 `breakthrough_pending`，不直接跳过剧情条件。
4. 每日更新位置、可见状态和普通对话；每天最多生成一个可重复的普通事件。
5. 每周检查晋升、成为竞争者、宗门职位变化和突破条件；每月检查离宗、转投其他宗门和长期目标变化。
6. 写入 `npc_cultivation_ledger`，更新 `last_simulated_date`，保证同一 NPC 和同一自然日幂等。

NPC 的修为更新不会直接改变用户修为或资源，只影响遇见时的对话、任务难度、帮助选项、竞争关系和世界事件。已与用户建立关系的 NPC 永久保留完整历史；普通未遇见人口可以只保留聚合统计，直到首次生成档案。

### 20.6 NPC 行程和遇见事件

NPC 每天拥有一个主活动和一个可选事件窗口。活动由宗门职位、当前状态和稳定日期种子决定，确保同一天重复打开页面不会重新随机：

| 主活动 | 典型地点 | 可触发内容 |
| --- | --- | --- |
| 修炼 | 功法阁、灵脉、演武场 | 请教、观摩、切磋 |
| 闭关 | 洞府、静室 | 等待出关、代送任务 |
| 外出任务 | 宗门外、地图节点 | 求援、护送、机缘事件 |
| 任务值守 | 任务堂、药房、器物坊 | 接取任务、兑换和委托 |
| 受伤恢复 | 药房、客舍 | 探望、代办和善缘事件 |

同一普通弟子每天最多触发一次重复事件；个人事件、晋升事件和离宗事件使用唯一 `event_key`。NPC 相遇不是凭空刷新的一次性卡片，而是对该 NPC 当前修为、行程、关系和历史事件的读取结果。

## 23. 任务模板和 NPC 任务池

每个任务模板包含：`template_id`、`source_role`、`task_tags`、`difficulty_range`、`importance_range`、`star_range`、`repeat_policy`、`reward_profile` 和 `unlock_condition`。

宗门任务池按 NPC 角色生成：

| NPC 角色 | 日常任务 | 每周任务 | 精英任务 |
| --- | --- | --- | --- |
| 任务执事 | 1-3 星宗门事务 | 4-5 星贡献任务 | 6 星宗门试炼 |
| 传功长老 | 1-2 星修炼记录 | 3-4 星功法理解 | 5 星功法试炼 |
| 宗主 | 无固定日常 | 5-6 星主线推进 | 7-9 星大境界主线 |

| 药房/器物执事 | 1-2 星材料任务 | 3-4 星制作项目 | 5 星配方试炼 |

每个宗门的三名固定核心 NPC 使用同一结构，普通弟子使用人口规则按需生成；任务标签、功法效果和地图主题不同。因此 90 个宗门可以通过数据配置产生完整差异，而不需要 90 套独立业务逻辑。

## 24. 内容完整性检查

种子数据加载时必须验证：

1. 恰好存在 9 个星级。
2. 每个星级恰好存在 10 个宗门，其中 6 个普通、3 个特殊、1 个隐藏。
3. 每个宗门恰好存在 3 个固定核心 NPC，并存在一条普通弟子人口规则。
4. 每个特殊宗门和隐藏宗门存在且仅存在一个签名功法；隐藏宗门还必须存在唯一现身条件。
5. 每个固定核心 NPC 都有稳定角色、地图、解锁条件和至少一个任务模板。
6. 每条普通弟子人口规则都定义总人口、活跃人口、按需生成和永久留存策略。
7. 每个大域都有主城、3 个普通区域、2 个秘境和 1 个突破地点。
8. 所有功法的冲突标签、占用格子和境界条件可解析。
9. 所有 NPC 每日修为流水具有 `npc_id + simulation_date` 唯一幂等键。
10. 仙界第一阶段恰好存在 3 个大仙域和 24 个地图节点，六大官署均有任务、职位和 NPC 配置。
11. 所有一次性奖励都有唯一 `event_key`。

这些检查应作为后端启动测试和独立内容完整性测试，不允许靠人工浏览发现缺数据。

## 26. 数值核算记录

炼气九层总修为需求：

```text
100 + 110 + 120 + 130 + 145 + 160 + 180 + 205 + 235 = 1385
```

在炼气期、修炼效率为 1.0 时：

| 每日普通任务数 | 习惯 | 每日基础修为 | 不计资质成长的周期 |
| ---: | ---: | ---: | ---: |
| 3 | 1 | 55 | 26 天 |
| 4 | 1 | 70 | 20 天 |
| 5 | 1 | 85 | 17 天 |

按每天 4 个普通任务和 1 个习惯模拟资质点转换，17 天累计约 1439 修为，达到筑基阈值并保留约 54 点余量。该结果支持“稳定用户约 17 至 20 天筑基”的目标；低活跃用户约 26 天，高活跃用户约 17 天。

灵石方面，普通任务按 0.40 比例结算，低活跃用户每天约 22 个灵石，高活跃用户每天约 34 个灵石。炼气阶段只能购买第 2 格，100 灵石约需 3 至 5 天；筑基后购买第 3、4 格需要更长积累，能形成境界与经济的双重成长，不会第一天完成全部格子购买。
