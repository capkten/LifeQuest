# LifeQuest 紧凑桌面端 UI 设计说明

## 目标

采用已确认的 A 方案：Windows 宽屏使用“固定侧边导航 + 居中双栏工作区”，减少重复卡片和过大留白，同时保留移动端紧凑任务工作台的视觉语言。

## 视觉规则

- 桌面内容铺满侧边栏以外的工作区；页面组件只在需要时自行设置内部列宽，避免宽屏右侧出现空白。
- 侧边栏保留完整导航，宽度从 260px 收敛到 232px；平板折叠行为不变。
- 首页主区域分为主任务列和辅助摘要列，主列约占 2/3，辅助列约占 1/3。
- 主任务区域使用一个欢迎/签到摘要和一个任务列表；统计、进度、成就归入辅助摘要。
- 卡片只承担区域分组，不为每个统计数字创建独立外框；统一使用 12–16px 间距和两级圆角。
- 颜色继续使用现有蓝色主题；字体本轮不锁定具体字体，只保留 `--font-family` 与 `--font-family-display` 变量供后续调整。
- 所有按钮保持至少 44px 高度；键盘焦点、对比度、移动端底部导航和无横向滚动不能回归。

## 实现范围

- `App.vue`：桌面宽度、间距、侧边栏和表面层级 token。
- `AppLayout.vue`：宽屏内容容器和页面节奏。
- `Sidebar.vue`：减少内部冗余空间，保持导航语义和折叠行为。
- `Home.vue`：宽屏双栏布局；移动端继续使用当前单栏布局。
- 不修改 API、状态管理、路由和业务数据结构。

## 验收

- 1440px 和 1024px 下首页呈现双栏且不横向溢出。
- 375px 下首页仍为单栏，底部导航不遮挡内容。
- 前端 `npm run build` 通过。
- 浏览器检查 Home、Todos、Shop、Profile 四个页面，确认共享壳层没有破坏页面宽度。
