# LifeQuest 笔记工作区与阅读/编辑模式设计

日期：2026-08-05

## 背景

当前笔记模块将笔记本列表、文件目录和笔记编辑拆成多个页面。进入笔记后会直接跳转到编辑/文件页面，打开具体笔记时目录上下文容易消失，用户无法一边浏览目录一边阅读笔记。

本次设计将笔记模块改造成持续存在的“笔记本工作区”：左侧保持文件夹/笔记树，右侧根据当前状态展示空状态、渲染后的笔记或编辑器。

## 目标

- 进入笔记本后始终保留目录上下文。
- 点击笔记默认进入阅读模式，不直接进入编辑器。
- 阅读模式展示渲染后的 Markdown，并提供明确的编辑入口。
- 编辑模式专注编辑，保存后回到当前笔记的阅读模式。
- 支持快速记录和长期知识整理两种使用方式。
- 保留现有笔记 API、Markdown 文件存储、图片上传和旧路由兼容性。
- 桌面端使用双栏工作区，移动端使用目录抽屉。

## 当前痛点与明确优化要求

以下问题是本次改造的明确范围，后续实现和验收不得只做概括性处理：

| 当前问题 | 明确优化要求 | 验收结果 |
| --- | --- | --- |
| 编辑完成后总是回到 `/notes` | 编辑器必须记录当前 `notebookId`、`parentId` 和来源路径；保存成功回到当前笔记的阅读模式，并保持左侧目录和当前文件夹位置 | 保存后仍处于原笔记本/原文件夹，不回到笔记本列表 |
| 新建笔记需要先进入笔记本再进入文件管理页 | 笔记本列表、工作区空状态和目录栏都提供“新建笔记”；支持在根目录或当前文件夹直接新建 | 新建操作最多一次进入编辑模式，不要求用户额外跳转文件管理页 |
| 没有最近编辑、置顶、收藏等快速入口 | 笔记本列表增加“最近编辑”和“置顶笔记”区域；笔记支持置顶；收藏如果没有独立后端字段，第一阶段使用 `is_pinned` 作为收藏/置顶能力，不重复造字段 | 用户从 `/notes` 可直接打开最近或置顶笔记 |
| 后端已支持 `summary`、`tags`、`is_pinned`，前端没有利用 | 阅读模式展示摘要、标签、置顶状态；编辑模式可以编辑摘要、标签和置顶；列表和搜索结果展示相关元数据 | 修改后重新进入笔记，元数据仍然存在并正确展示 |
| 搜索结果只有全局搜索 | 搜索支持按笔记本、文件夹/路径、标签、更新时间范围和置顶状态筛选；筛选条件可以清除；搜索结果展示所在位置 | 用户可以从搜索结果判断笔记归属并直接进入阅读模式 |
| 编辑器只有手动保存 | 增加“未保存/保存中/已保存/保存失败”状态；内容变更后使用防抖自动保存；保留手动保存按钮 | 网络正常时编辑内容自动保存，状态可见；保存失败时可重试 |
| 没有离开页面未保存提醒 | 编辑器检测未保存变更；返回、切换路由、点击目录或关闭编辑模式时提示确认 | 有未保存内容时不会静默丢失 |
| 文件夹和笔记管理偏传统文件系统，整理成本高 | 工作区提供最近访问、置顶、排序、搜索、标签筛选；目录支持快速新建、重命名、移动；后续评估拖拽移动、批量操作和回收站 | 常用笔记不需要多层目录逐级查找；高级整理能力单独分期 |
| 笔记列表缺少排序、最近打开、字数、更新时间 | 列表/搜索结果支持按最近编辑、最近打开、创建时间、标题排序，并展示字数、更新时间、所在路径；最近打开记录必须后端持久化并跨设备同步 | 用户在不同设备登录后仍能看到一致的最近打开笔记，且排序和元数据显示正确 |

## 信息架构与路由

| 路由 | 用途 |
| --- | --- |
| `/notes` | 笔记本列表、最近笔记和全局搜索入口 |
| `/notes/:notebookId` | 笔记本工作区，未选择笔记时显示工作区空状态 |
| `/notes/:notebookId/view/:noteId` | 工作区内阅读指定笔记 |
| `/notes/:notebookId/edit/:noteId` | 工作区上下文中的编辑模式 |
| `/notes/:notebookId/new` | 在当前笔记本根目录新建笔记 |
| `/notes/:notebookId/new?parent_id=...` | 在指定文件夹中新建笔记 |

保留现有 `/notes/edit/:id` 和 `/notes/new/:notebookId` 作为兼容入口。兼容入口需要解析笔记所属笔记本，随后重定向到新的工作区阅读/编辑路由，不改变旧链接的可用性。

## 工作区布局

### 桌面端

左侧为固定宽度或可调整宽度的目录栏，右侧为内容区。目录栏包含：

- 当前笔记本名称、描述和返回笔记本列表入口。
- 面包屑或当前路径提示。
- 可展开/折叠的文件夹树。
- 当前笔记高亮状态。
- 新建文件夹、新建笔记操作。
- 节点重命名、移动、删除操作。

右侧根据状态显示：

- 未选中笔记：工作区欢迎状态和快速新建入口。
- 阅读模式：笔记标题、更新时间、字数、标签、摘要、渲染 Markdown 和操作栏。
- 编辑模式：标题、摘要、标签、置顶开关、Markdown 编辑器、保存状态和返回阅读入口。

### 移动端

- 默认只显示内容区，目录通过顶部“目录”按钮打开抽屉。
- 选择笔记后自动关闭抽屉并进入阅读模式。
- 抽屉中保留创建、展开、重命名、移动和删除操作。
- 编辑模式全屏显示，底部导航和安全区不遮挡编辑器及保存操作。
- 目录抽屉关闭后仍保留当前选中笔记和阅读位置。

## 模式与状态流转

```text
笔记本列表
    ↓ 进入笔记本
工作区空状态
    ↓ 点击笔记
阅读模式 ← 保存完成 ← 编辑模式
    ↓ 点击编辑
编辑模式
```

- 点击目录中的笔记只改变当前 `noteId` 和右侧内容，不离开工作区。
- 点击“编辑”进入编辑路由；编辑器加载失败时保留目录并显示错误状态。
- 保存成功后回到对应笔记的阅读模式，并保留 notebookId、parentId 和当前路径。
- 返回按钮优先返回阅读模式；从新建页面取消时返回当前文件夹。
- 离开有未保存修改的编辑器时提示确认。
- 自动保存采用防抖策略，显示“未保存/保存中/已保存/保存失败”状态；手动保存仍保留。
- 编辑器需要维护 `dirty` 状态。标题、正文、摘要、标签或置顶变化都标记为未保存；自动保存成功后清除 `dirty` 状态。
- 目录切换、阅读/编辑模式切换、浏览器返回和路由离开都必须经过未保存保护。

## 笔记元数据

现有后端已经支持以下字段，前端需要在阅读和编辑模式中真正使用：

- `summary`：摘要，可在阅读头部和列表预览中展示。
- `tags`：标签，支持编辑和筛选。
- `is_pinned`：置顶状态，支持阅读页和列表操作。
- `word_count`：字数统计。
- `created_at`、`updated_at`：创建和更新时间。
- `last_opened_at`：最近一次进入阅读模式的时间，后端持久化，用于跨设备的最近打开列表和排序。

笔记本列表增加最近编辑、置顶笔记和全局搜索入口。搜索结果展示笔记本/文件夹路径、标签、摘要和更新时间。

## 数据与 API 约束

继续使用现有 `noteService` 与后端接口：

- notebooks：获取、创建、更新、删除笔记本。
- tree/children：加载目录树和当前目录内容。
- notes：创建、读取、更新笔记内容及元数据。
- nodes：重命名、移动、删除文件夹/笔记。
- search：全局搜索。
- upload-image：Markdown 图片上传。

需要新增的后端能力：

- `POST /api/notes/{note_id}/open`：用户进入阅读模式时记录 `last_opened_at`，操作幂等，只允许记录当前用户拥有的笔记。
- `GET /api/notes/recent`：返回当前用户最近打开的笔记，支持 `limit`，结果包含笔记本、路径、标签、摘要、字数和时间字段。
- 笔记列表/搜索接口增加排序和筛选参数，或提供等价的聚合接口；必须支持最近打开、最近编辑、创建时间和标题排序。
- `NodeResponse` 与 `NoteDetailResponse` 增加 `last_opened_at` 字段。

记录打开时间只在进入阅读模式时触发，不在目录树加载、搜索结果加载或编辑器后台请求中误更新。打开同一笔记的频繁请求应使用前端去重或后端限频，避免无意义写入。需要后端新增接口时单独增加 schema、service、API 和测试。

## 组件职责

- `Notes.vue`：笔记本列表、最近/置顶入口、全局搜索。
- `NotebookFileManage.vue`：笔记本工作区、目录树、抽屉状态、当前选择和阅读模式容器。
- `NoteViewer.vue`：渲染 Markdown、元数据、阅读操作栏和编辑入口。
- `NoteEditor.vue`：编辑标题/摘要/标签/置顶、Markdown 内容、保存和自动保存状态。
- 可复用目录组件：负责树节点展示、展开/折叠、选中态和节点操作，避免桌面栏与移动抽屉重复实现业务逻辑。

第一阶段可以先在现有 `NotebookFileManage.vue` 中承载工作区和阅读容器；当文件规模影响维护性时，再抽取 `NoteViewer.vue` 和目录组件，业务 API 不变。

## 分阶段实现

### Phase 1：工作区和阅读模式

- 调整路由和工作区状态。
- 保留左侧目录，右侧增加笔记阅读模式。
- 点击笔记不再直接进入编辑器。
- 增加阅读页编辑入口和正确返回路径。
- 移动端目录抽屉化。
- 笔记本列表和工作区空状态提供快速新建笔记入口。
- 保存/返回必须恢复原笔记本、原文件夹和当前目录位置。

### Phase 2：编辑体验

- 编辑页增加摘要、标签、置顶。
- 增加自动保存和保存状态。
- 增加未保存离开提醒。
- 保存后回到当前笔记阅读模式。
- 自动保存覆盖标题、正文、摘要、标签和置顶状态，失败后保留重试入口。

### Phase 3：查找和整理

- 最近编辑、置顶笔记。
- 标签筛选和排序。
- 搜索结果增加路径、标签、摘要、更新时间。
- 笔记列表展示字数、最近编辑时间、最近打开时间和所在路径。
- 搜索支持笔记本、路径、标签、更新时间范围和置顶状态筛选。
- 新增最近打开接口、`last_opened_at` 字段、权限校验、排序逻辑和跨用户隔离测试。
- 评估拖拽移动、批量操作和回收站。

## 验收标准

- 桌面端进入笔记本后，左侧目录始终可见；点击不同笔记只更新右侧内容。
- 默认阅读模式展示渲染后的 Markdown，编辑按钮能进入编辑模式。
- 保存后回到当前笔记阅读模式，不丢失笔记本和文件夹上下文。
- 移动端目录可通过抽屉访问，选择笔记后抽屉自动关闭。
- 新建、重命名、移动、删除、图片上传和 Markdown 内容保存行为保持可用。
- 有标签、摘要、置顶和更新时间的真实数据可以正确展示和编辑。
- 375px、768px、1024px、1440px 下无页面级横向溢出。
- 笔记相关后端测试全部通过，新增行为有对应测试覆盖。
