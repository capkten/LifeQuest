## 规格落地约定

- 采用任务卡中具体的验收项；书信实现周期性周信与每周试炼，伙伴实现已解锁灵宠的免费随行切换。
- B 规则任务仅在本次成功收功中完成时按 0.5 转化；此前已完成按 0.25；提前结束不完成任务。
- 每日 240 灵气按收功所在中国日记账；超过目标时间不会继续获得灵气。
- 历史会话保持旧规则，不补发、不重算。05 的新归来结算覆盖 HTTP/MCP 等所有新 B 规则会话的首次终结；已经终结的旧 B 会话也不补发额外奖励。
- 今日签采用固定 1.1 倍基础入定修为，向下取整；额外部分独立记账，不放大任务或奇遇奖励。当天首次有灵气的收功（含提前结束）使用；零灵气不消耗机会。首次成功的凡品奇遇保底独立，不被提前结束消耗。
- 零灵气只允许奇遇故事/图鉴解锁，不产生入定或被动额外资源；真实任务完成仍按自身规则独立发奖。
- 归来只查看不会清除标记，明确点击「回洞府」才确认已收好。
- 保留现有奇遇目录及概率；凡品存在 50/75 修为或 60 灵石奖励，可能明显大于单段 B 基础收益，未在本次擅自改数值。固定用例：25 分钟、本次完成任务、首次签加成、50 修为奇遇，分别为基础 12、任务 15、签 1、奇遇 50，合计 78 修为、16 灵石；基础 B 的 12/7 快照不变。
- 首次引导结束只显示白鹿剪影，第三次成功入定才解锁。
- 书信以注册所在中国日期为第 1 天；第 7/14 天开放青蘅/砺锋首信，之后周一 08:00 生成周信。延迟打开时按首次符合条件的读取冻结正文和变量，不补一串错过的周信，不重写已送达的正文。每周可接受性由服务端返回，前端不另算周界。
- 完整离线支持以任务 09 为准：继续已有会话计时并排队收功；不离线创建服务器会话、不排队完成任务。

## 08 通知与降级增量

- Android 使用系统倒计时常驻通知与同 ID 的结束本地通知，支持回到入定和收功动作；不靠后台 JavaScript 每秒运行，也不新增前台服务。通知动作先验证当前账号与会话，并重新检查八成收功资格，不能通过旧通知提前发奖。
- 只在开始入定或设置按钮的明确手势后请求系统通知；拒绝不阻断入定。关闭偏好持久化，登出/切换账号清理通知与未完成动作。首次 Android 落座说明声音默认开启，可一键关闭。
- 使用当前校准后的服务端时间同步通知，不把旧快照时间当作此刻；点击埋点记录类型、客户端报告延迟和服务端冻结会话状态，不发奖励、不确认归来。
- Android local-notifications 8.0.2 仅检查精确提醒资格，不自动打开系统特殊授权设置；未授予时明确显示锁屏/省电可能延迟。Windows 仅承诺应用运行时原生提醒，不承诺退出后定时或点击激活。
- Web 说明先记录缺失区域的 RED，再实现后 GREEN。后续原生接线通过浏览器外部 Tauri 通知桥边界模拟拒绝，业务仍使用真实 HTTP，验证不自动请求、手势拒绝后可开始、关闭偏好刷新保留；该接线用例不冒称实施前逐项 RED，也不代替 Windows/Android 真机验收。
- 最终构建后同源浏览器 3/3 通过；开发服务转发测试另一次出现 teardown 的 `Route is already handled`，未将那次计为通过，同源重跑无转发且通过。设置页已实际打开并检查截图，无横向溢出。

## 09 离线与待收功增量

- 按用户保存版本化缓存与待收功队列；缓存保留校准后的时差，不把旧 `server_now` 重新当作当前时间。跨中国日期收起旧今日签、三签和今日计数，保留标注日期的会话与待收功。
- 冷启动读账号资料只在无 HTTP 响应的网络错误/超时后恢复匹配当前 JWT 用户 ID 的本地资料；真实 401 拒绝仍退出登录，另一账号不能恢复前一账号的洞府。未将本地资料作为服务端授权。
- 收功在发送前持久冻结请求 ID 与提前结束意图。已保存的排队结果只显示等待确认，不提前显示修为、奇遇或任务完成，也不播放成功提示。可先回洞府继续浏览；联网确认后进入正式归来，清除待收功提示。
- 真实页面已复现缺少离线展示、缺少等待收功状态、离线任务按钮仍可点的 RED；对应最小实现后 GREEN。离线任务完成置灰并显示联网说明，恢复网络不会补发任务完成请求。
- 真实 API 网络边界验收已通过：首次收功 POST 断网→刷新→同一 UUID/提前结束 payload 重试→服务端收据，绑定任务仍未完成；另真实等待一分钟成功入定，在服务端发奖后丢弃响应，刷新重试得到相同收据，修为/灵石没有再增加。跨页待收功与联网后自动归来也已通过。
- 缓存身份的 401/跨账号拒绝、跨页导航与真实丢失响应是额外回归，不冒称每个分支都有实施前独立页面 RED。公开状态/系统适配边界另覆盖时钟、稳定 payload、退避、存储失败与账号切换竞态。
- 浏览器断网验收控制的是 HTTP/浏览器网络边界，应用壳由已运行的本地应用提供；不将其描述为新建了完整离线 PWA，也未代替 Android 飞行模式真机验收。
