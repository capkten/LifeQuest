# MCP OAuth Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans. Track steps below.

**Goal:** OAuth login and secure MCP access compatible with ChatGPT discovery, preserving existing clients.
**Architecture:** Persisted OAuth Service, thin FastAPI routes, shared MCP bearer verifier and Vue consent page.
**Tech Stack:** FastAPI, SQLAlchemy, existing MCP SDK, Vue 3, pytest, node:test.
**Spec:** docs/superpowers/specs/2026-10-26-mcp-oauth-design.md

## Global Constraints
UTF-8; isolated data; no production, merge or real user mutations. Existing PAT/SSE/stdio behavior retained. URL configuration is explicit and OAuth disabled by default. Secrets stored hashed. PKCE S256 and explicit consent required. Only authorization_code/refresh_token grants. Tokens never in URLs. Root VERSION sole source.

### Task 1: OAuth persistence and service
Files: backend/app/models/mcp_oauth.py, backend/app/models/__init__.py, backend/app/services/mcp_oauth.py, backend/tests/test_mcp_oauth_service.py.
Consumes app.oauth_config.get_oauth_config() with config fields enabled,issuer_url,resource_url,frontend_url,access_seconds,refresh_seconds,request_seconds,code_seconds,allow_loopback.
Produces MCP OAuth service interface documented below. Write actual lifecycle/security tests first, observe failures, implement, run tests, commit only task files.
- [x] RED: register public client; begin request; bind consent to user; approve and exchange code with exact S256 verifier.
- [x] GREEN: persistence and public/confidential client flows.
- [x] RED/GREEN: bad redirect/PKCE/resource/scope; code replay; expiry; token hashes; refresh replay; grant revocation and user/client isolation.

Service contract: MCPOAuthService(db); OAuthError(error,error_description,status_code=400). register_client(payload:dict)->dict; begin_authorization(params:dict)->str request handle; authorization_details(request_id,user_id)->dict; consent(request_id,user_id,approve:bool)->str callback; exchange_token(form:dict,authorization:str|None=None)->dict; revoke_token(form:dict,authorization:str|None=None)->None; authenticate_access_token(raw_token:str)->UUID|None; list_grants(user_id)->list[dict]; revoke_grant(grant_id,user_id)->None. Exceptions expose error,error_description,status_code. Details keys: client_name,redirect_uri,scope,resource,user_id. Registration returns raw client_secret only once for confidential clients. Other metadata excludes credential hashes.
