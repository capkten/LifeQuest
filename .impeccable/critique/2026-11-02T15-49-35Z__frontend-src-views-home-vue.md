## 设计特异性判定：3 / 10

**这段构图属于"待办看板"，不属于 LifeQuest。**

剥掉文案，没有任何东西能标识这个产品。骨架是 `指标条 → 快速新增 → 重点卡 → 2×2 分组面板 → 侧边栏`，这是 Vercel Geist / Element Plus 后台 / Linear inbox 的形状。把「修为」换成 Streak、「灵石」换成 Credits，它可以原样当成习惯打卡应用发货。

具体证据：

- **配色不是决策，是默认值。** `--color-primary #0284C7`（sky-600）、`--color-accent #10B981`（emerald-500）、`--color-error #EF4444`（red-500）、`--color-bg #F8FAFC`（slate-50）——全是 Tailwind 出厂色。而且已经漂移了：全局覆盖层用 `rgba(14,165,233,…)`（sky-500），`TodayActionCenter.vue:430` 和 `:554` 硬编码 `#17324d`（不在任何 token 里）。**同一页上共存两种蓝。**
- **字体没有决策。** 两套字体栈在中文设备上落到同一套系统字体，字号出现 10 / 10.5 / 11 / 12 / 13 / 13.5 / 15 / 16px 七档，没有节奏。
- **10px / 800 字重 / `letter-spacing:.14em` / `text-transform:uppercase` 的 kicker**（`.aside-card-kicker`、`.cultivation-eyebrow`、`.nav-section-label`）是把英文微标签的习惯套在中文上——`uppercase` 对汉字是空操作，0.14em 字距只会让"修炼状态"散开。这是整页最明显的"模板从西方后台搬来"的痕迹。
- **产品灵魂被塞进一条只读条。** 修仙只出现在 112px 高、蓝渐变、三个胶囊计数的 `CultivationStatusBar` 里，它不在行动面上。你可以在这一页把一天做完，而修炼层从头到尾没有在发生动作的地方反应过一次。

**确定性扫描**（`impeccable detect`，退出码 2，共 3 条）：

|---|---|---|
| `Home.vue:599` | `bounce-easing` | 真阳性：`.checkin-btn` hover 的 `cubic-bezier(0.34,1.56,0.64,1)` 确实过冲 |
| `TodayActionCenter.vue:298` | `side-tab` | 语义误报：指标块本身有完整边框，这是非对称强调而非装饰色条 |
| `TodayActionCenter.vue:461` | `side-tab` | **实际不渲染** —— 见下方"探测器与人工评审的交汇点" |

**可视化叠加层**：无。没有启动服务、没有注入脚本，所以不存在任何用户可见的覆盖层。

### 探测器与人工评审的交汇点

探测器在 `TodayActionCenter.vue:461` 报了 `border-left: 3px solid var(--color-error)`。人工评审独立发现同一个元素上 `border-color: rgba(239,68,68,.15)` 这个简写把左边框改回了淡色——**这条 3px 红边从来没有渲染出来过**。它是"逾期"状态在视觉上唯一的载体，而它一直是死的。同理 `:319-321` 的 `--danger` / `--success` 也是同一个自毁模式。

探测器赌中了元素，人工评审赌中了它为什么不生效。这就是为什么两条链路都要跑。

## 总体印象

工程质量明显高于这个体量该有的水平——状态管理、幂等、`prefers-reduced-motion`、44px 触控，都是真的在管。产品思维也真存在，但在两处：四个日期分组，和"三件事"是个服务端对象而不是一个高亮。

设计失败是**构图性**的：五个面在抢唯一重要的那个面；核心动作的奖励渲染在离点击 800px 之外的另一张卡里；美学是出厂 slate/blue，里面没有修仙。

而你给的参考稿解决的是**层级和情绪**，不是**特异性**。它把六个面收成一个面，这是对的；但薄荷底 + 柔和照片 + 三张马卡龙重点卡，换到任何看板上都成立。照抄它能得到"安静的一天总览"，得不到"这是 LifeQuest"。

---

## 做对了什么

1. **四个日期分组是真模型，不是装饰。** 今日到期 / 已经逾期 / 未安排时间 / 稍后到期，是对"我的一天"最正确的一刀。而且每组空态都带语气决策——逾期组写"没有逾期任务，继续保持。"而不是羞辱用户。多数看板不做这个。
2. **重点是服务端一等对象。** `今天最重要的三件事` 限三项、按中国日持久化、明确不改变任务原优先级、完成后仍保留、有 `moveFocus` 上下排序和关闭后焦点回到触发器。多数任务应用用一个星号图标糊过去。
3. **组件级状态纪律。** 骨架屏、`aria-busy`、`role="alert"`、区分"失败"与"失败但保留上次内容"、44px 最小触控、全局 reduced-motion 开关。这是让页面在层级失衡的情况下依然"值得信任"的原因。

## 优先问题

### [P0] 三套并行的"今天"账本，没有唯一焦点源

**问题**：`TodayWorkbench` 的四个时间桶和 `TodayActionCenter` 的四个类型分区都在列今天的和逾期任务；hero 卡再加一个"今日待办"计数，行动中心再加第三条指标条和一条"下一步"横幅。**同一个任务可以在同一屏出现三次。**

**为什么重要**：这是在产品原则 3（后端是业务真相）上从界面层破防——两个视图对同一批数据用不同的查询和不同的 `slice`，"今日到期 2"和"今天安排 3"完全可能同时成立。数字一旦对不上，用户就不再相信首页，"每天只打开一个地方"的承诺当场失效。同时每个任务点哪里都是 1/3 的猜。

**修法**：一份查询、一份列表。把逾期 / 今天安排并进 workbench 的分组，把习惯和日程作为同组网格里再多两组。删掉 `Home.vue:71-79` 的 `<TodayActionCenter>`，删掉"下一步"组件——`next_action` 就是今日到期第一行加一条"接下来"缎带。三组指标并进 workbench 的四指标条，全页只留一条。

**命令**：`/impeccable distill` → `/impeccable layout`

### [P0] 移动端首屏没有任何任务

**问题**：小于 1200px 时堆叠顺序是：工作台头部（眉标 + h2 + 日期 + 两个按钮）→ 四指标 2×2 → 三字段快速新增表单 → 重点区 → 四个任务组 → 页脚 → **然后才是**深蓝 hero → 修炼条 → 行动中心 → 快捷行动 → 最近任务/目标 → 习惯环。375×667 下第一个任务行落在 800–900px 处。

**为什么重要**：PRODUCT 写明 375/390 是固定验收尺寸、Android 是出货目标。Casey 在通勤路上打开应用想知道今天干什么，她得到的是一个标题、两个按钮、四个灰框和一个表单。这一页唯一的工作在主要移动面上失败。另外 `.nav-item { min-height: 36px }` 违反了项目自己的 44px 规则，而那 17 行是移动端通往 13 个模块的唯一路径。

**修法**：`<768px` 时指标压成一行数字 + 11px 标签；重点卡提到首屏；快速新增收成一行 `＋ 写下下一步…`，聚焦再展开；hero、修炼条、最近列表、习惯环移到任务组之下或砍掉。`.nav-item` 提到 44px。

**命令**：`/impeccable layout`

### [P1] 新用户的空状态是一个 28px 旋转圆环

**问题**（已逐行核实，`Home.vue:1097-1113`）：

```css
.loading-state,
.empty-state,

.loading-spinner {
  width: 28px; height: 28px;
  border: 3px solid var(--color-border);
  border-top-color: var(--color-primary);
  border-radius: 50%;
  animation: spin 0.8s linear infinite;
}
```

`.empty-state` 被写进了加载圆环的选择器里。后面那条 `.empty-state` 规则只补了 `color` 和 `font-size`，没有清掉宽高、圆角、边框和旋转。所以 `暂无任务，创建你的第一个任务吧！` 实际渲染成 **28×28 的旋转圆环，文字从圈里溢出来**。

**为什么重要**：这是首次运行体验——用户决定这个产品能不能用的那十秒。它读起来就是"页面坏了"。

**修法**：拆开选择器。空态改成 `padding:32px 16px; border:1px dashed; border-radius` + 一个真 CTA，文案改成邀请（"今天还没有安排。写下第一件事…"）。`.loading-state` / `.loading-spinner` 在本文件是死代码，整段删掉。

**命令**：`/impeccable polish`（文案与 CTA 交给 `/impeccable onboard`）

### [P1] 完成任务没有就地奖励

**问题**：反馈是固定右上角的 toast（`z-index:2000`）+ `.hero-meta-item` 的金币脉冲 + 一次无声的修炼刷新。点击发生在 y≈900 的行上，奖励出现在视口另一角或已经滚走的卡里。

**为什么重要**：PRODUCT 的定位就是"奖励绑定在真实完成上"，而界面把回报藏到 800px 外。峰终定律下，会话的高峰是全页反馈最弱的一刻，习惯回路因此失去了电荷。

**修法**：让那一行自己变形——成功后该行元信息变成 `+12 修为 · +4 灵石`（数值取自完成响应，不在前端重算，遵守原则 3），停留约 2.5s；被完成的那张重点卡同步进入已完成态。把 hero 的金币脉冲换成指标条里唯一一个 `今日已修行 +N`。任务成功的 toast 取消，错误 toast 保留。

**命令**：`/impeccable delight` + `/impeccable animate`

### [P1] 与参考稿的构图差距，以及照抄也补不上的身份

**问题**：参考稿的全部主张是**一块白面**浮在薄荷底 + 柔光照片上：一行 hero（先行动，再成长 / 今日工作台 / 日期）→ 四个指标横向铺开、之间用淡色字形分隔 → 单行快速新增 → 三张**马卡龙渐变**的重点卡（空槽也画出来）→ 四块平铺面板、行间用发丝线分隔、右侧中性计数胶囊。现状是：深蓝渐变 hero、蓝调修炼条、带边框的行动中心、嵌套卡片的快捷行动、会 hover 抬起的惰性最近列表、conic 习惯环。

**为什么重要**：这一条是"差距"不是"缺陷"，但它就是这一页读起来像"五个互不相关的部件"而不是"我的一天"的原因。具体：`.task-group` 是一张 12px 圆角卡嵌在 `.today-workbench` 卡**里面**（卡中卡）；`.focus-task-card` 是平铺底色加一个蓝色"重点 1"标签，而不是三个色阶；空的重点状态是一段虚线文字，而不是三个可点的槽位。

**修法**：删掉 `hero-card`、`.home-aside-actions`、`.content-grid`、`.habit-progress-card` 和整段 `.daily-*`。一个面。加 `--rank-1/2/3` 三档柔和渐变 token；三张重点卡永远渲染，空的那个本身就是选择器（省一次点击，也和参考稿一致）。指标条改成一行、字形分隔。四个面板去嵌套，改发丝线分隔。画布用薄荷渐变 + 一个柔和径向，`--glass-*` 变量已经存在且未使用。

**但请注意**：这一条只把层级修对。要拿到身份，还需要第二个动作——重点卡按境界着色、完成时就地出现修为、三项重点带上篆/印线索。否则照抄完，唯一还带温度的元素就是那三张马卡龙卡，任何看板也能用。

**命令**：`/impeccable shape` → `/impeccable colorize`

## 角色红旗

### Alex（重度用户，每天 10+ 任务）

- **没有键盘路径**。快速新增是鼠标目标；`focusQuickAdd()` 存在但没绑任何键。从页面加载起 tab 约 19 次才进主区，而且**全应用没有跳过导航的链接**（`AppLayout.vue:3` 在 `:6` 之前）。
- **完成被串行化**。`completingKey !== null` 和 `busy` 会禁用**所有**行。清 8 个任务要等 8 次。
- **没有就地推迟**。每个"查看"都跳去 `/todos`，为首页最常见的逾期分诊动作丢掉了上下文。
- **静默后台刷新**。`window focus` 与 `visibilitychange` 都会 refetch；Android 上每次切回都会在他拇指下方重排列表。

### Sam（键盘 / 读屏）

- **主反馈没有被朗读**。`Home.vue:194-211` 的两个 toast **没有 `role="status"`、没有 `aria-live`**，而代码库其它页面（Todos、Shop、Finance、Projects）全都加了——偏偏首页没有。于是完成任务对读屏是静默的；同时 `.cultivation-status-bar` 把 `aria-live="polite"` 加在整个区块上，Sam 听到的是三个数字，而不是"已完成"。
- **标签挂在了收不到标签的元素上**。`.workbench-metrics`、`.today-action-metrics` 是没有 `role` 的裸 `<div>` 加 `aria-label`，辅助技术忽略。
- **标题轮廓错位**。`h2 今日工作台` 在 `h1 欢迎回来` 之前。
- **对比度与字号**。`--color-text-tertiary #94A3B8` 在白底上是 **2.56:1**（`.aside-card-kicker`，10px）——远低于 AA 4.5:1，且 10px 对中文本身就偏小。hero 上的 `rgba(255,255,255,.76)` 10px 在渐变最亮停靠点 `#0369A1` 上约 **4.13:1**，同样不达标。全站 12 处以上把正文设在 10–10.5px。
- **重点编辑器语义不对**。触发器的 `aria-expanded` 绑在一个会 `v-if` 掉触发器本身的状态上，永远为 `false`；`Esc` 只绑在 `<form>` 上；没有 dialog 角色、没有焦点陷阱。

### Casey（移动端单手）

- **首屏没有可点的事**（见 P0），完成一个任务要滚约 1.5 屏。
- **触控目标不达标**：`.today-action-item-open` 是 34px，`.nav-item` 是 36px，而项目自己的规则是 44px。
- **toast 盖住导航**：移动端覆盖层把它拉成整宽固定在顶部，`z-index:2000` 压在 sticky header 和汉堡键之上，toast 存在期间 Casey 看不见导航。
- **快速新增要三下加一个键盘**：`<600px` 下三个堆叠全宽字段。参考稿是一行搞定。

## 次要观察

1. **`var(--text-secondary)` 与 `var(--border-color)` 根本不存在**（`TodayActionCenter.vue:425/435/551`，全仓库无定义）。后果是分组计数继承近黑色、分隔线回落到 `currentColor`。
2. **`.today-action-item--overdue` 的颜色声明是死的**，只有那 3px 边框在标记逾期——而那条边框也被上文的简写覆盖掉了。逾期状态目前**没有任何有效视觉**。
3. **惰性元素会 hover 抬起**：`.task-item`、`.goal-item`、`.hero-meta-item` 都有 `translateY(-1px)` + 白底 + 阴影，共 10 行"假 affordance"。
4. **`Home.vue` 里约 200 行死 CSS**：所有 `.daily-*` 规则、`dailyHabitBlockReason()`、`completeDailyHabit()` 都没有对应元素或调用者。
5. **习惯百分比在同一张卡里印了两遍**（`:182` 和 `:186`）。
6. **"（中国时间）"一屏出现三次**，其中一次在每一行的元信息里。时区是全局事实，说一次就够。
7. **未安排时间组的每一行都写"未设置截止时间"**——标题已经说了。
8. **`0/0 今日重点进展`** 在没选重点时应读作"未选择重点"。
9. **桌面栅格是手写行号**（`grid-row: 1…6` + `.content-grid { display: contents }`），已经空出第 6 行第 1 列，非常脆。
10. **`refreshHomeTasks` 刷新任务和行动中心，但不刷新目标**（`:347-349`）。
11. **一屏 7 个请求**：`Home.vue` 挂载 6 个 fetch 加 `TodayWorkbench` 自己的 `load()`，其中两个在算同一件事。
12. **`.section-link { width: 100% }`** 在移动端把每个"查看全部"顶成独占一行的全宽块。

## 值得想的问题

1. **如果奖励是你的护城河，为什么这一页唯一的奖励面是和侧边栏长得一样的数字条？** 如果把 header 以下所有数字全删掉，「三件事 + 四个分组」还是不是产品？如果还是，那些数字就是装饰。
2. **今日到期和今天安排是同一批任务的两个名字，算了两遍。** 它们某天差了一行时，用户该信哪个？他刚完成一件事之后，这个答案还成立吗？如果你不能一句话回答，它们就该是一个列表。
3. **"欢迎回来，冒险者！"除了证明页面渲染成功，还做了什么？** 参考稿直接把它删了。用户每天都登录，天天被"欢迎回来"接待是大堂，不是工作台。
4. **23:00 时这一页最平静的收尾应该是什么？** 现在是一个 148px 的 conic 环，同一个百分比印两遍。最后的印象该是一个数字，还是一句话——"今日完成 6 件，修为 +134，筑基三层"？
5. **43 项在稍后到期里，它是列表，还是一个事实？** 五行窗口看向 43 件事，是最糟的两头不靠：够让人焦虑，不够让人行动。
6. **新账号看到的是：三个空组、`0/0`、一个旋转圆环、"暂无任务"。** 这十秒你想教会的是哪一件事——"这是个修仙游戏"，还是"写下今天必须做的一件真事"？现在是六件事，所以一件都没教会。
